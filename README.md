# Codespring

## Objetivo
Este repositório é um template base para qualquer projeto de hackathon.

Não está ligado a nenhuma ideia específica.

---

## Stack

### Backend
- Java (Spring Boot)
- REST API

### Frontend
- React (Vite)

---

## Princípio do projeto

- Backend e frontend são independentes
- Comunicação via API REST (JSON)
- Tudo deve ser simples e rápido

---

## Estrutura

backend/   → API
frontend/  → UI
docs/      → documentação

---

## Como começar

### Backend
cd backend
./mvnw spring-boot:run

### Frontend
cd frontend
npm install
npm run dev

---

## Regra da equipa

1. Primeiro definir API
2. Depois implementar backend
3. Depois ligar frontend

---

## Organização

- Tech Lead: define arquitetura e API
- Backend dev: Java API
- Frontend dev: UI
- Integrador: liga tudo
- Helper/tester: QA e debugging
